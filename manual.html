為什麼要做兩件事，不能只做一件

單靠瀏覽器設定不夠——只要小朋友的帳號有「系統管理員」權限，他隨手就能改掉或刪掉下面做的設定。所以要「帳號權限」和「瀏覽器原則」兩道關卡一起上，缺一道，另一道就形同虛設。

STEP 01

建立小朋友的「標準使用者」帳號

這一步是整份手冊最重要的一步——沒有它，後面設定的原則隨時會被解除。

  1. 設定 → 帳戶 → 家人與其他使用者 → 按「新增帳戶」。
  2. 帳戶類型選擇「標準使用者」，絕對不要選「系統管理員」。
  3. 用家長自己的帳號密碼繼續操作本手冊剩下的步驟（第 02～04 步都要用系統管理員身分執行）。
  4. 設定完成後，把系統管理員密碼收好，不要讓小朋友知道。

順序提醒

先用管理員帳號把 02、03、04 步的原則都設好，最後才把小朋友的日常登入切到標準使用者帳號，避免中途卡在「沒有權限」的畫面。

STEP 02

設定 Edge 的網址白名單

用「登錄編輯器」(regedit) 寫入原則。Windows 11 Home 沒有群組原則編輯器，但登錄編輯器一樣有效。

  1. 用系統管理員帳號登入，按 ⊞ Win 鍵，輸入 regedit，按 Enter，出現詢問時選「是」。
  2. 在上方網址列貼上以下路徑，按 Enter 直接跳過去： HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Edge 如果 Edge 資料夾不存在，在 Microsoft 上按右鍵 → 新增 → 機碼，命名為 Edge。
  3. 在 Edge 上按右鍵 → 新增 → 機碼，命名為 URLBlocklist。點進去，在空白處按右鍵 → 新增 → 字串值，名稱打 1，雙擊打開，數值填 *。
  4. 回到 Edge，同樣新增一個機碼 URLAllowlist。點進去，逐一新增字串值 1、2、3……，每一筆的數值填一個要開放的網址。
  5. 回到 Edge 這一層，新增下表三個 DWORD (32 位元) 值，用來關掉無痕模式、關掉登入切換、關掉開發人員工具。
HKLM\SOFTWARE\Policies\Microsoft\Edge\URLBlocklist（字串值）
名稱類型數值
1REG_SZ*
HKLM\SOFTWARE\Policies\Microsoft\Edge\URLAllowlist（字串值，逐一新增）

STEP 03

設定 Chrome 的網址白名單

做法跟 Edge 幾乎一樣，只是路徑換成 Google\Chrome，而且「停用無痕模式」的機碼名稱不同（見上方圖1）。如果這台筆電只用 Edge，這一步可以跳過。

Edge 路徑

HKLM\SOFTWARE\Policies\Microsoft\Edge

無痕模式機碼：InPrivateModeAvailability

Chrome 路徑

HKLM\SOFTWARE\Policies\Google\Chrome

無痕模式機碼：IncognitoModeAvailability

  1. 在登錄編輯器網址列貼上： HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome 資料夾不存在就自己新增機碼（做法同 Edge 那一步）。
  2. 在 Chrome 下新增機碼 URLBlocklist，新增字串值 1 = *。
  3. 新增機碼 URLAllowlist，逐一新增字串值 1、2……，數值填要開放的網址（跟 Edge 那份名單一樣即可）。
  4. 在 Chrome 這層新增下表的 DWORD 值。
HKLM\SOFTWARE\Policies\Google\Chrome（DWORD 32 位元值）
名稱類型數值作用
IncognitoModeAvailabilityDWORD1停用無痕視窗
BrowserSigninDWORD0不能切換登入別的帳號
DeveloperToolsAvailabilityDWORD2關閉開發人員工具
STEP 04

防止小朋友繞過限制

前面兩步鎖住了 Edge 和 Chrome，這一步確保他沒有「第三條路」。

  1. 檢查這台筆電目前裝了哪些瀏覽器：只留 Edge（和/或 Chrome），把其他瀏覽器（Firefox、Opera 等）移除，或替它們也套用同樣的 URLBlocklist／URLAllowlist 原則（機碼路徑改成對應廠商的資料夾）。
  2. 確認小朋友的帳號真的是標準使用者（回到 STEP 01 檢查）——這樣他打開安裝檔時會被 UAC 視窗擋下，需要輸入管理員密碼。
  3. 把家長自己的系統管理員密碼設成小朋友猜不到的組合，不要用生日、名字。
STEP 05

驗證清單

用小朋友的帳號登入後，逐項打勾確認。（打勾狀態只存在這台裝置的瀏覽器裡，換裝置檢視不會保留。）

常見問題

白名單網站打不開，一直顯示已封鎖怎麼辦？

最常見原因是子網域沒有分別列出——例如只加了 example.com，但小朋友真正要開的是 m.example.com 或 www.example.com。把實際網址列裡看到的完整網域，一字不差地加進 URLAllowlist 的下一個編號。

需要一直保持連網才會生效嗎？

不需要。這些設定寫在登錄檔（本機），開機後 Edge／Chrome 一啟動就會套用，離線也一樣有效。只有第一次打開這份手冊的網頁需要網路。

之後想再新增或移除允許的網站怎麼做？

用管理員帳號打開 regedit，回到 URLAllowlist 那個機碼，新增下一個編號的字串值，或直接修改／刪除既有的值即可，不用重灌或重新跑一次全部步驟。改完建議重開一次瀏覽器。

可以用「家人集中管理」(Microsoft Family Safety) 取代這份手冊嗎？

Family Safety 介面更親民、有使用時間報表，但它的網站限制需要小朋友用微軟帳號登入，而且防護強度不如「標準使用者 + 登錄原則」這麼硬，較懂電腦的孩子仍有機會繞過。兩者也可以並用：Family Safety 顧使用時間，這份手冊的設定負責硬性鎖網址。
