為什麼建議同時勾選 Edge 與 Chrome？

為避免孩子在其中一個瀏覽器被封鎖時，自行切換至另一個瀏覽器瀏覽未核准網站，強烈建議同時鎖定所有已安裝的瀏覽器。系統會直接把白名單寫入 Windows 登錄機碼 (Registry)，即使重新安裝瀏覽器亦會維持封鎖。
