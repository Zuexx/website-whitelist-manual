步驟 3：設定防繞過與進階防護選項

啟用以下選項可防止孩子嘗試透過瀏覽器設定、無痕模式或開發人員工具繞過白名單限制。建議全數維持開啟以達成無漏洞防護。

visibility_off
停用無痕視窗 (InPrivate / Incognito) verified 強烈推薦 (預設開啟)

防止孩子建立不會留下瀏覽紀錄、且可能避開特定快取檢驗的無痕分頁，確保所有上網行為皆受白名單政策嚴格控管。

terminal Windows 原則值：IncognitoModeAvailability = 1 (強制停用無痕)
code_off
停用開發人員工具 (Developer Tools / F12) verified 強烈推薦 (預設開啟)

封鎖鍵盤 F12 與滑鼠右鍵「檢查元素」功能，避免具備技術好奇心的孩子透過控制台修改本機腳本或偽裝網路封包。

terminal Windows 原則值：DeveloperToolsDisabled = 1 (完全停用 F12 控制台)
manage_accounts
停用帳號切換與訪客模式 (Guest Mode & Profile Switching) verified 強烈推薦 (預設開啟)

禁止在瀏覽器中新增其他訪客個人設定檔或任意切換未受管的微軟 / Google 帳號，確保白名單防護不會被多帳號登入繞過。

terminal Windows 原則值：BrowserGuestModeEnabled = 0, SigninAllowed = false
health_and_safety
貼心提示：獨立受管帳號隔離

這些群組原則僅套用於孩子的受保護帳號（王小明）。您的家長管理者帳號依然保留完整的瀏覽器所有功能與擴充外掛，日常工作完全不會受到干擾。
